# AI 数字人双端使用说明

## 运行方式

AI 数字人模型和 WebRTC 服务运行在电脑上，电脑作为直播主机；手机和 PC 共用同一个直播工作台。手机端不需要安装 Python 或模型，只需要浏览器。

1. 在电脑上双击 `E:\AiLive\一键启动AI数字人.cmd`。
2. 启动窗口会打印 PC 地址和手机地址，例如：
   `http://192.168.1.104:8010/live_console.html`
3. 让手机和电脑连接同一个 Wi-Fi。
4. 在手机浏览器打开打印出的手机地址。
5. 在浏览器菜单中选择“添加到主屏幕”，即可作为手机应用使用。

## 手机开播流程

1. 在手机工作台切换账号、录入商品、生成话术。
2. 打开“9:16 直播输出窗口”，允许浏览器使用摄像头和麦克风。
3. 输出窗口保持打开，回到工作台执行“开播预检”和“一键开播”。
4. 根据抖音、视频号或其他平台的官方直播工具要求，将输出窗口作为窗口/屏幕采集源。
5. 直播过程中可直接用手机暂停话术、人工播报、切换商品或安全下播。

## 双端说明

- PC 和手机访问的是同一个 `/live_console.html`，账号、商品、话术和直播状态实时同步。
- PC 端保留完整宽屏工作台；手机端自动切换为单列布局和大触控按钮。
- 手机端可以执行账号管理、商品管理、开播预检、开播、下播和人工接管。
- 账号与商品写操作只允许本机或同一局域网设备，服务不会主动开放公网。
- 如果手机无法访问，请确认电脑防火墙允许 TCP `8010`，并确认两台设备不在访客 Wi-Fi 或不同网段。

## 能力边界

当前方案是“电脑运行模型，手机控制和使用”。如果需要完全脱离电脑、让模型直接运行在 Android/iPhone 上，需要另行进行模型移动端转换、硬件适配和平台推流开发。
