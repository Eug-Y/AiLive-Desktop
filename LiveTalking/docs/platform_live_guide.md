# 视频号 / 抖音 AI 数字人直播落地手册

## 当前采用的接入方式

本机尚未安装 OBS、OBS 虚拟摄像头、`pyvirtualcam` 或 RTMP 推流库。为了减少依赖，当前使用平台官方直播工具的**窗口采集**功能：

```text
LiveTalking WebRTC 数字人
        ↓
9:16 干净直播输出窗口（画面 + TTS 音频）
        ↓
抖音直播伴侣 / 视频号官方直播工具窗口采集
        ↓
平台直播间
```

这种方式不需要暴露推流密钥，也不依赖 OBS。若账号未来取得 RTMP 推流地址，可再启用直接 RTMP 方案。

## 一键启动

双击 `E:\AiLive\一键启动AI数字人.cmd`。启动完成后浏览器会打开：

- 直播控制台：`http://127.0.0.1:8010/live_console.html`
- 完整网页教程：`http://127.0.0.1:8010/affiliate_tutorial.html`
- 控制台中的“打开9:16直播输出窗口”会创建单独的干净画面窗口。

服务未启动时，可直接查看 `E:\AiLive\docs\AI达人带货直播完整教程.md`。

停播后双击 `E:\AiLive\停止AI直播服务.cmd`。

## 开播前设置

1. 在“大模型管理”中配置 DeepSeek、通义千问或自定义模型，并完成连接测试。
2. 在直播控制台填写直播标题和 AI 标识。
3. 打开9:16输出窗口，在窗口中点击“启动直播画面”。
4. 用“人工插话”发送一段测试文字，确认画面、声音、口型和字幕均正常。
5. 如需识别直播画面中的字幕或评论，进入“字幕自动回应”，只框选目标文字区域。
6. 保存自动直播话术。首次测试时不要立即启用循环，先观察一轮。
7. 建议先开始本地录制，完成至少1分钟的彩排。

## 抖音直播伴侣

当前电脑安装的是普通抖音客户端，并未检测到“抖音直播伴侣”。请从抖音官方渠道安装直播伴侣并登录有开播权限的账号。

在直播伴侣中：

1. 新建竖屏直播，画布建议 `1080 × 1920`，帧率 `25` 或 `30`。
2. 添加“窗口采集”，选择“AI 数字人直播输出”窗口。
3. 将采集源铺满画布；完整人物模式建议保持比例，裁切模式可铺满。
4. 启用系统音频或应用音频采集，数字人说话时电平表必须跳动。
5. 不要采集“AI 数字人直播工作台”窗口，避免控制按钮出现在直播中。
6. 先使用测试直播或低可见范围验证，再正式开播。

## 微信视频号

当前电脑检测到“微信小店助手”，但未确认安装了具备窗口采集能力的“视频号直播助手”。请通过视频号创作者后台或官方渠道取得对应直播工具和开播权限。

配置原则与抖音相同：

1. 选择竖屏 `1080 × 1920` 或与账号内容匹配的横屏规格。
2. 添加窗口采集，选择“AI 数字人直播输出”。
3. 开启电脑/应用音频采集并观察音量电平。
4. 商品、价格、优惠和售后话术必须与小店后台实际信息一致。

## 直播工作台功能

- **开播检查中心**：综合商品、话术、数字人输出、AI 标识和人工确认，计算开播准备度；修改商品、话术或画面后会要求重新复核。
- **运营配置备份**：导出商品库、内部佣金、设置、话术和检查项，不包含任何 API Key。
- **达人商品库**：保存平台商品 ID、已核对价格、优惠、卖点、适用人群以及内部佣金；佣金不会传给大模型或数字人口播。
- **当前讲品**：问答只使用当前商品的已核对资料。未选择商品或资料缺失时，数字人会提示以商品卡/客服说明为准。
- **自动讲品**：为已核对且已授权的商品生成开场、卖点、适用人群、用法、价格提示和商品卡引导话术。
- **合规拦截**：保存商品、人工直播、自动话术和大模型回答都会检查内置风险表述与商品专属禁用词。
- **人工插话**：直接播报指定文本，或将问题交给当前大模型回答。
- **自动话术**：数字人空闲时逐条播报，可设置循环与间隔。
- **字幕自动回应**：OCR 检测到稳定新字幕后调用大模型，自动话术会主动让路。
- **人工打断**：清空当前播报，但保留自动任务。
- **紧急停止**：暂停自动话术、停止 OCR 自动回应并打断当前内容。
- **本地录制**：用于开播前彩排和故障复盘。

准备度达到100%只代表本系统必做项通过，不能代替平台端的资质、商品卡、风险提示和正式开播确认。

## 防止错误循环

- OCR 只能框选外部直播字幕或评论区，不能框选数字人自己的回答字幕。
- 输出窗口不能遮挡被 OCR 框选的目标区域。
- 建议两次回应至少间隔5秒，同一字幕120秒内不重复回应。
- 保持人工值守；出现错误信息、违规问题或重复播报时立即点击“紧急停止自动内容”。

## 合规与内容安全

- 仅使用本人或已取得明确授权的人脸、声音、商品素材和音乐。
- 画面保留“AI 数字人”与 LiveTalking 标识，并按平台要求声明 AI 生成。
- 不得冒充真人，不得使用虚假功效、绝对化承诺、虚假价格或未经确认的库存信息。
- 自动生成内容必须由真人值守并可随时接管，不能把无人值守作为默认运营方式。
- 平台规则和账号权限可能调整，最终以开播时平台官方规则为准。

## 达人佣金带货流程

1. 在平台官方达人选品入口选择允许推广的商品，确认类目资质、佣金和结算条件。
2. 在工作台商品库录入商品资料；佣金率和预估佣金仅作为内部运营信息。
3. 对照直播间商品卡逐项核对价格、优惠、卖点和售后边界，并确认推广素材已授权。
4. 勾选“信息已核对”和“素材已授权”，再点击“设为当前商品”。
5. 点击“生成并应用话术”，人工检查全部话术后进行私密或本地录制彩排。
6. 在平台直播工具中挂载同一件商品，确认工作台当前商品与平台商品卡一致后开播。
7. 商品价格、优惠或库存发生变化时，先暂停自动话术，更新并重新核对商品资料。

系统不会代替达人账号完成选品、挂车、佣金结算或平台开播，也不能保证收益。

## 当前未自动完成的外部步骤

以下操作必须由账号所有者完成：

- 实名认证、视频号/抖音开播权限和相关类目资质；
- 下载、登录和同意平台直播工具条款；
- 商品上架、价格、库存、优惠券和售后配置；
- 点击平台端“开始直播”和“结束直播”；
- RTMP 推流地址或推流密钥的获取与保管。
