# 直播字幕自动回应

此功能截取本机屏幕中指定的字幕区域，通过本地 RapidOCR 识别文字，去重后交给当前大模型回答，再由数字人完成 TTS 播报和口型同步。

## 使用顺序

1. 启动 LiveTalking，打开 `/index.html` 并点击“开始连接”。
2. 打开 `/llm.html`：
   - 选择 DeepSeek、通义千问或自定义 OpenAI 兼容接口；
   - 保存对应 API Key；
   - 点击“测试当前模型”，确认可以返回内容。
3. 打开 `/subtitle.html`：
   - 刷新并选择当前数字人会话；
   - 点击“3秒后截取屏幕”，倒计时期间切换到直播画面；
   - 回到控制页，在截图上拖动框选字幕区域；
   - 点击“开始监控”，然后将控制页最小化或移出框选区域。

## 默认防重复策略

- 每 500 毫秒扫描一次字幕区域；
- 相同字幕连续识别两次后才确认；
- 已回应字幕在 120 秒内不会重复触发；
- 两次回答之间至少间隔 5 秒；
- OCR 区域文字过多时停止触发，避免误把整个屏幕交给大模型。

## 大模型配置

支持以下服务：

| 服务商 | 默认接口 | 常用模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat`、`deepseek-reasoner` |
| 通义千问 | DashScope OpenAI 兼容接口 | `qwen-turbo`、`qwen-plus`、`qwen-max` |
| 自定义 | 用户填写 | Ollama 或其他 OpenAI 兼容模型 |

API Key 只能通过本机 `127.0.0.1` 页面保存，保存在项目 `.env` 文件中；接口不会返回或回显已保存的密钥。

## 直播注意事项

- 控制页或其他窗口不能遮挡被框选的字幕区域。
- 字幕区域应尽量只包含一到两行字幕，避免主播名、弹幕和按钮混入。
- 正式直播前先关闭“自动回应”，观察 OCR 结果是否稳定；确认无误后再开启。
- 对自动生成内容保持人工值守，避免未经审核的内容直接发布。
