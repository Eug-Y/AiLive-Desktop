1. 盈利与系统路径

01达人联盟选品
02平台挂商品卡
03AI 数字人讲解
04观众下单成交
05平台结算佣金

本系统负责数字人画面、语音合成（TTS）、商品话术、评论字幕识别和智能答疑；平台账号、选品、挂车、订单、退款与佣金结算仍由平台官方系统负责。

收益提示
佣金不是保证收益。计算净收益时还要考虑退货、样品、投流、人工值守和账号运营成本。

2. 首次准备（只做一次）

完成达人实名认证，并确认直播、带货和对应类目权限。
从平台官方渠道安装抖音直播伴侣或视频号直播工具。
双击 E:\AiLive\一键启动AI数字人.cmd，等待工作台打开。
进入“大模型管理”，选择 DeepSeek、通义千问或自定义兼容模型；接口密钥（API Key）只在本机页面填写，不要发到聊天。
用模型测试按钮确认回答正常。
准备已获得授权的数字人肖像、声音、商品图片、视频和音乐。

3. 每件商品的选品与录入

字段怎么填注意事项
平台商品 ID复制商品卡/选品中心中的准确 ID用于防止挂错品
价格与优惠写明当前到手信息和领券方式变价后必须重新核对
卖点每行一条，只写商品卡或商家确认的信息不编造功效、销量和体验
适用人群/用法以说明书和商品参数为准不做诊断或个体效果承诺
佣金后台记录佣金率和预估单佣不会传给模型或口播
商品禁用词一行一个，加入该商品特别容易违规的说法与内置合规规则叠加
先保存草稿。
逐项对照平台商品卡。
确认素材推广授权。
最后勾选“信息已核对”和“素材已授权”。

4. 生成并审核讲品话术

在商品列表点击“设为当前商品”。
点击“生成并应用话术”。
逐条人工阅读自动话术，确认商品名称、价格、优惠和卖点准确。
需要修改时直接编辑“自动直播话术”，保存后必须重新彩排。
不要把佣金、内部选品理由或商家私下承诺写入口播。
安全机制
系统切换商品、修改当前商品或重新保存话术时，会自动撤销相关检查项，防止沿用旧商品话术。

5. 开播前检查中心

按照工作台“开播 SOP 检查中心”处理红色阻塞项。准备度达到 100% 只代表本系统检查通过，仍要在平台端完成最终确认。

达人带货、直播和类目权限正常
当前商品与平台商品卡完全一致
商品已挂到直播间
数字人输出已连接
画面保留 AI 数字人标识
自动话术已生成并人工复核
声音、口型和平台音频电平正常
至少完成 1 分钟彩排
真人值守人员已就位

6. 抖音 / 视频号官方工具配置

新建竖屏画布，建议 1080×1920，帧率 25 或 30。
工作台点击“打开 9:16 直播输出窗口”，再在输出窗口点击“启动直播画面”。
官方直播工具添加“窗口采集”，只选择“AI 数字人直播输出”。
开启系统音频或应用音频采集，确认数字人说话时电平跳动。
挂载与工作台当前商品相同的商品卡。
先做私密/低可见测试，再公开开播。
画面安全
不要采集控制台窗口，不要把接口密钥、佣金、后台订单或观众隐私显示在直播画面里。

7. 直播中的标准操作

自动讲品

点击“启动自动话术”。OCR 正在回答时，自动话术会暂时让路。

人工插话

紧急说明、纠错或平台活动信息使用“直接播报”；观众商品问题使用“大模型回答”，回答会绑定当前商品资料。

字幕/评论识别

01打开字幕 OCR 页面并截屏
02只框选平台评论或字幕区域，不能框选数字人自己的字幕
03观察几轮后再开启自动回应

人工值守

持续观察平台警告、商品状态、库存/价格变化、重复回答和音画异常。

8. 安全换品顺序

暂停自动话术。
在平台直播工具中准备下一件商品卡，但先不要让数字人讲。
工作台点击“切换下一件可用商品”或指定“设为当前商品”。
生成并人工检查新商品话术。
确认平台挂载商品与工作台当前商品一致。
重新勾选商品匹配、挂品和彩排检查。
恢复自动话术。

9. 应急处置

情况立即操作
说错价格/商品点击“紧急停止自动内容”→ 平台下架错误商品卡 → 人工纠正
重复回答/自问自答紧急停止 → 停止 OCR → 重新框选评论区域
模型出现违规内容人工打断 → 暂停智能回答 → 保存记录并修正商品禁用词
无声音/黑屏暂停自动内容 → 检查输出窗口与平台采集源 → 必要时结束平台直播
平台警告立即停止相关内容，按平台提示整改；不要尝试规避审核

10. 下播后的复盘

先在平台端结束直播，再停止自动话术和 OCR。
双击 E:\AiLive\停止AI直播服务.cmd。
记录每件商品的曝光、点击、成交、退款、佣金和问题类型。
标记高频问题，补充到商品资料；不确定的信息交给商家确认。
删除失效优惠和停推商品。
计算：预估净佣金 = 结算佣金 − 退款扣回 − 投流 − 样品/素材 − 人工成本。

11. 配置备份

在检查中心点击“备份运营配置”，会下载包含商品库、佣金、设置、话术和检查项的 JSON 文件。

备份不包含任何大模型接口密钥。
备份含内部佣金，请保存在受控目录，不要发到直播群或公开网盘。
建议每次大批量换品后备份一次。
.env 含模型密钥，不能上传、截图或分享。

12. 常见故障

现象处理
8010 页面打不开重新双击启动脚本，检查 server.live.stderr.log
输出窗口无声音先点击“启动直播画面”；检查浏览器音量和平台应用音频采集
数字人不说话确认输出已连接、语音合成网络可用、话术未被合规拦截
模型不回答检查接口密钥、模型连接测试和当前商品资料
OCR 一直重复缩小识别区域，避开数字人回答字幕，提高冷却时间
换品后没有话术这是安全机制；为新商品重新点击“生成并应用话术”
准备度下降改商品、话术或画面后需要重新核对和彩排

13. 合规红线

不得虚构价格、库存、销量、用户评价、认证、赠品或售后。
不得承诺全网最低、百分百有效、根治、无副作用、稳赚等结果。
不得使用未经授权的人脸、声音、音乐和商家素材。
必须保留 AI 标识并安排真人值守。
健康、食品、美妆、金融等敏感类目必须按平台与法律要求补充资质和风险提示。
最终以开播当日平台规则和商品卡实时信息为准。

14. 断网保命（离线语音缓存）

高频问题（价格、规格、发货、售后等）先由意图直答秒回，不调用大模型。把这些话术提前合成到本地语音缓存后，断网也能播，而且接近零延迟。

联网状态下执行 E:\AiLive\env\python.exe E:\AiLive\tools\prewarm_tts_cache.py。
看到“新建 0 条 / 命中已有全部 / 失败 0 条”即预热完成。
回到工作台“开播 SOP 检查中心”，确认“离线语音缓存已覆盖高频话术”显示已覆盖。
新增商品、修改价格或话术后，话术清单会变化，必须重新预热。
预热和播放使用同一音色（config.yaml 的 REF_FILE），换音色后要重新预热。
没预热的新话术仍可播，但需联网合成；断网时会失败并交给人工处理。
