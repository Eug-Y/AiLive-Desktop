# AI 达人带货直播完整教程

适用目录：`E:\AiLive`  
适用平台：抖音、微信视频号等支持窗口采集的官方直播工具。

> 本系统负责数字人画面、语音、话术、字幕识别和商品问答；平台实名认证、选品、挂商品卡、订单、退款与佣金结算仍由平台官方系统负责。佣金不是保证收益。

## 一、每次直播的完整顺序

1. 在平台官方达人选品入口确认商品仍可推广、佣金和类目权限正常。
2. 双击 `E:\AiLive\启动AI直播工作台.cmd`。
3. 在商品库录入或更新平台商品 ID、价格、优惠、卖点、适用人群、用法和内部佣金。
4. 对照平台商品卡核对资料，确认素材授权，然后勾选两项确认。
5. 设为当前商品，点击“生成并应用话术”，人工逐条审核。
6. 配置并测试大模型。Key 只在本机网页填写，不要发送给任何人。
7. 打开9:16输出窗口，点击“启动直播画面”。
8. 在抖音/视频号官方直播工具中添加窗口采集与应用音频采集。
9. 在平台挂载与工作台当前商品完全相同的商品卡。
10. 人工播报一段测试话术，检查声音、口型、画面和平台音频电平。
11. 如需自动识别评论，框选评论区并启动 OCR；不要框到数字人自己的字幕。
12. 完成至少1分钟私密或本地彩排。
13. 在“开播 SOP 检查中心”逐项确认，准备度达到100%。
14. 真人值守到位后，在平台官方工具点击开始直播。
15. 下播时先结束平台直播，再停止 OCR、自动话术和本机服务。

## 二、首次准备

- 达人账号已实名认证。
- 已取得直播、带货和对应商品类目权限。
- 已从官方渠道安装平台直播工具。
- 数字人肖像、声音、商品图片、视频和音乐均已授权。
- DeepSeek、通义千问或自定义模型已完成连接测试。
- 工作台地址：`http://127.0.0.1:8010/live_console.html`
- 大模型管理：`http://127.0.0.1:8010/llm.html`
- 字幕 OCR：`http://127.0.0.1:8010/subtitle.html`
- 网页教程：`http://127.0.0.1:8010/affiliate_tutorial.html`

## 三、商品录入标准

| 字段 | 填写方法 | 风险控制 |
|---|---|---|
| 平台商品 ID | 从选品中心或商品卡复制 | 防止挂错品 |
| 价格 | 填写当前已核对的到手信息 | 变价后重新核对 |
| 优惠 | 填写领券或活动方式 | 不承诺未生效优惠 |
| 卖点 | 每行一条，仅使用商品卡/商家确认信息 | 不编造功效、销量和体验 |
| 适用人群和用法 | 以说明书、参数页为准 | 不做个体效果承诺 |
| 佣金 | 只作后台运营记录 | 不传给模型，不口播 |
| 商品禁用词 | 一行一个 | 与内置规则叠加拦截 |

只有勾选“信息已核对”和“素材已授权”的商品才能设为当前商品和生成自动话术。

## 四、直播中操作

### 自动讲品

数字人空闲时逐条播报。OCR 正在回答观众问题时，自动话术会让路。

### 人工接管

- 紧急通知和纠错：使用“直接播报”。
- 商品问题：使用“大模型回答”，模型只得到当前商品已核对资料。
- 需要停止当前声音：点击“仅打断播报”。
- 出现错品、违规或循环：点击“紧急停止自动内容”。

### 安全换品

1. 暂停自动话术。
2. 切换工作台当前商品。
3. 重新生成并审核新商品话术。
4. 在平台挂载同一商品卡。
5. 重新确认商品匹配、挂品和彩排检查项。
6. 恢复自动话术。

切换、删除、修改当前商品或修改话术时，系统会自动清空/撤销相关旧状态，这是防止串品的安全机制。

## 五、应急处理

| 情况 | 立即处理 |
|---|---|
| 说错价格或商品 | 紧急停止 → 下架错误商品卡 → 人工纠正 |
| OCR 自问自答 | 紧急停止 → 停止 OCR → 重新框选评论区 |
| 模型违规回答 | 人工打断 → 暂停智能回答 → 增加商品禁用词 |
| 黑屏或无声 | 暂停自动内容 → 检查输出窗口和平台采集源 |
| 平台警告 | 立即停止相关内容并按平台要求整改 |

## 六、下播复盘

每件商品至少记录：

- 曝光人数、商品点击、成交单数、成交金额；
- 退款单数、最终结算佣金；
- 投流、样品、素材和人工值守成本；
- 高频问题、被拦截表述、错品/错价情况；
- 下一场需要修改的卖点、禁用词和排品顺序。

参考计算：

`预估净佣金 = 最终结算佣金 - 退款扣回 - 投流 - 样品/素材 - 人工成本`

## 七、配置备份

在工作台点击“备份运营配置”，下载 JSON 文件。备份包含商品库、佣金、话术、画面设置和检查项，但不包含任何大模型 API Key。

- 备份包含内部佣金，应保存在受控目录。
- `.env` 文件包含模型密钥，不得上传、截图或分享。
- 建议每次大批量换品和稳定配置后各备份一次。

## 八、故障排查

### 8010 页面打不开

重新运行启动脚本，查看 `E:\AiLive\server.live.stderr.log`。如果端口被其他程序占用，先确认占用进程再处理。

### 输出窗口没有声音

先点击输出窗口中的“启动直播画面”，检查浏览器音量，再确认平台官方工具已采集系统/应用音频且电平会跳动。

### 数字人不说话

确认输出窗口已经连接；检查 Edge TTS 网络；检查话术是否被违禁词规则拦截。

### 大模型不回答

检查 API Key、模型连接测试、账户余额/额度以及当前商品资料。

### OCR 重复回答

缩小识别区域，只框选外部评论/字幕；避开数字人回答字幕；提高冷却时间。

### 换品后话术为空

这是安全机制。选择新商品并重新点击“生成并应用话术”。

### 准备度突然下降

修改画面、商品或话术后，需要重新检查音视频、商品卡匹配和私密彩排。

## 九、合规红线

- 不虚构价格、库存、销量、用户评价、认证、赠品和售后。
- 不承诺全网最低、百分百有效、根治、无副作用、稳赚等结果。
- 不使用未经授权的人脸、声音、音乐和商家素材。
- 画面保留 AI 数字人标识，直播全程真人值守。
- 健康、食品、美妆、金融等敏感类目必须满足平台和法律资质要求。
- 最终以开播当日平台规则和商品卡实时信息为准。

## 十、启动与停止

- 启动：双击 `E:\AiLive\启动AI直播工作台.cmd`
- 停止：双击 `E:\AiLive\停止AI直播服务.cmd`

不要通过强制关机代替正常停播。先结束平台直播，再停止本机服务。
