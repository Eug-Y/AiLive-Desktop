# 登录与会员（激活码）功能说明

本文说明 AI 数字人直播工作台的账号体系：谁能用哪些功能、管理员怎么卖、用户怎么解锁、出问题怎么处理。

## 一、角色与套餐

| 角色 | 套餐 | 能力 |
| --- | --- | --- |
| 管理员 `admin` | 管理员 | 全部功能 + 用户/激活码管理 + 大模型 API Key + 数字人素材 |
| 普通用户 | 免费版 `free` | 登录工作台、查看状态与商品库、模拟评论测试、看教程 |
| 普通用户 | 专业版 `pro`（购买/兑换后） | 连接数字人、开播下播、自动话术、人工播报、录制、字幕回应、商品与佣金管理、备份导出、达人账号管理 |

**永远不受套餐限制的安全操作**：安全下播、紧急停止、打断播报。免费用户也能停播，避免因为没付费而无法止损。

> **「加锁」和「看不见」是两种处理方式**，别混用：
> - 会员能升级解锁的功能（开播、录制、导出……）→ 用 `data-feature="..."` 或 `data-feature-lock="..."`，
>   普通用户**看得见但被加锁**，点了会弹出升级提示 —— 这是刻意的，让人知道有这功能、可以买。
> - 管理员专属、不该让普通用户知道的东西（如「参赛项目」）→ 用 `data-hide-without="competition.view"`，
>   普通用户**整个入口直接不显示**（导航项、卡片都藏掉），页面地址也被服务端挡到 `forbidden.html`。
>
> 隐藏逻辑写在 **`common.js`（导航的生成者）**里：它自己读一次 `/api/auth/me`，页面若装了 `auth.js`
> 就直接复用其状态（不重复请求）。**不要**把这类隐藏写进某个页面的内联脚本 —— 全站 24 个页面共用
> 同一个导航，只有写在导航里才处处生效（`auth.js` 只被 3 个页面引入，放那里会漏掉其余 21 页）。
> 元素默认先藏、确认有权限才显示，普通人连"一闪而过"都看不到。

## 三、首次启动

1. 启动服务（双击 `一键启动AI数字人.cmd`）后，控制台会打印：

   ```
   [AUTH] 登录与会员体系已启用（存储目录：E:\AiLive\LiveTalking\data\auth）
   [AUTH] 已创建初始管理员：admin，密码：admin123456（默认），请登录后立即修改！
   ```

2. 打开 `http://127.0.0.1:8010/` 会跳到登录页 `login.html`。
3. 用 `admin / admin123456` 登录。工作台顶部会一直提示"你仍在使用初始管理员密码"，点「修改密码」立即改掉。
4. 初始密码同时写在 `LiveTalking/data/auth/初始管理员密码.txt`。

想换初始密码，可以在启动前设置环境变量：

```powershell
$env:AILIVE_ADMIN_PASSWORD = "你的强密码"
$env:AILIVE_ADMIN_USER = "boss"      # 可选，改管理员用户名
```

> **本机现状（2026-10-10）**：管理员口令**已经不是**默认的 `admin123456` 了 —— 已按你的要求设置，
> 默认口令实测返回 401（失效）。默认口令只在**第一次启动、从来没改过**的时候才有意义：
> 一旦改掉，`初始管理员密码.txt` 里记的就是历史值，别再照着它登录。
> 改过密码之后，跑自检脚本要这样带上口令（脚本不写死密码）：
>
> ```powershell
> $env:AILIVE_ADMIN_USER = "你的管理员用户名"
> $env:AILIVE_ADMIN_PASSWORD = "你的密码"
> E:\AiLive\env\python.exe E:\AiLive\tools\smoke\_e2e_auth_ui.py
> E:\AiLive\env\python.exe E:\AiLive\tools\smoke\_cleanup_test_data.py --apply
> ```

**密码规则**（服务端与前端一致，都按这个校验）：至少 8 位、最多 128 位，且**必须同时包含字母和数字**
—— 纯数字（如 `54185418`）或纯字母都会被拒绝。改密码时如果不符合，弹窗会**红字**提示并且不会关闭，
不会出现"以为改好了其实没生效"的情况。

## 四、用户怎么用

1. 打开登录页 → 「注册」标签 → 填用户名、密码（至少 8 位，含字母和数字）→ 注册后自动登录，套餐为**免费版**。
2. 免费版在工作台里能看到：状态概览、开播检查清单、商品库列表、模拟评论测试（只看判定链路，不让数字人播报）、教程。
3. 想开播：点顶部「升级会员」→ 打开 `upgrade.html` → 扫码/联系客服付款 → 把客服给的激活码填进「兑换激活码」→ 立即解锁专业版。
4. 兑换成功后立刻生效，无需重启服务；再次兑换会在现有到期时间上**叠加**天数。
5. 专业版到期后自动回落为免费版，页面会提示"专业版已过期，重新兑换即可恢复"。

## 五、管理员怎么卖（激活码）

打开工作台右上角「用户管理」，或直接访问 `http://127.0.0.1:8010/admin_users.html`。

- **生成激活码**：填天数（默认 30）、数量、每码可用次数、码有效期（0 = 永久）、备注 → 生成后点「复制全部」，发给已付款的用户。
- **激活码格式**：`AILIVE-XXXX-XXXX-XXXX`，字母表已去掉 `0/O/1/I` 等易混字符。用户输入时大小写、空格、不带横线都能识别。
- **作废**：用户退款或发错码时点「作废」，该码立即失效（已兑换的会员不受影响）。
- **用户管理**：改角色、改套餐、手动设到期时间、重置密码、禁用（会立即踢下线）、强制下线、删除。系统强制保留至少一个管理员。
- **登录设置**：自助注册开关、登录总开关、默认天数、联系方式、购买说明（会显示在升级页）。

## 六、关闭登录（兼容旧用法）

临时不想让人登录，可以整体关闭鉴权：

```powershell
$env:AILIVE_AUTH = "off"        # 或改 data/auth/config.json 里的 enabled=false
$env:AILIVE_ALLOW_REGISTER = "off"   # 只关自助注册
```

关闭后所有接口不再校验登录，行为与旧版本一致（写操作仍受"仅本机/内网"限制）。
**注意**：关闭后前台所有人（含访客）都能开播和进后台，只在完全可信的内网临时使用。

## 七、数据与安全

| 位置 | 内容 |
| --- | --- |
| `LiveTalking/data/auth/users.json` | 用户与密码哈希（PBKDF2-SHA256，20 万次迭代，随机盐） |
| `LiveTalking/data/auth/sessions.json` | 登录会话（7 天有效，重启服务不掉线） |
| `LiveTalking/data/auth/codes.json` | 激活码与使用记录 |
| `LiveTalking/data/auth/config.json` | 登录设置（开关、联系方式等） |

- 会话令牌放在 `HttpOnly` Cookie 里，前端脚本读不到；接口也支持 `Authorization: Bearer <token>`。
- 登录失败 5 分钟内超过 8 次会被限流；注册每 IP 每小时最多 5 次。
- `data/` 目录已被 `.gitignore` 忽略，不会把用户数据提交进仓库。
- 修改密码或重置密码会让该用户**其它设备**的会话立即失效。

### 同一账号只允许一处登录（默认开启）

一个账号同时在多处登录时，**后来的登录会把先前的挤下线**（"后来者顶下去"）：
新登录成功后，该账号在其它设备/浏览器上的会话立即作废，那台设备下一次点任何页面
都会跳回登录页（页面上有提示："同一账号同一时间只能在一处登录"）。
目的是避免一个付费账号被多人/多台设备同时使用。

- **管理员不受限**：管理员可以同时在多个浏览器登录，自检脚本也照常用管理员账号，
  不会把本人的登录挤掉（否则每跑一次自检就掉一次线）。
- 开关位置：「用户管理 → 登录设置 → 同一账号只允许一处登录」，默认勾选。
- 环境变量 `AILIVE_SINGLE_SESSION=off` 可临时整体关掉（例如排查登录问题时）。
- 关闭这个开关后，仍然保留"改密码会把其它设备踢下线"这条独立保护（两者互不影响）。
- 实现位置：`server/auth_manager.py` 的 `login()`（挤会话）+ `single_session` 属性（开关）。

## 八、把界面分享给别人看

| 分享方式 | 谁能打开 | 需要的条件 |
| --- | --- | --- |
| 局域网（现成可用） | 同一 Wi-Fi / 网线的电脑、手机 | 无，服务已监听 `0.0.0.0`，防火墙已放行 |
| 外网（云隧道，现成可用） | 任何人，只要有网络 | 双击 `外网分享给别人看.cmd`，把窗口里的 `https://xxx.trycloudflare.com` 发给他 |
| 外网（固定域名/长期） | 同上 | 需要 Cloudflare 账号绑定自有域名，或用带域名的服务器反代 |

**局域网**：地址形如 `http://172.16.40.169:8010/live_console.html`（启动器与「接入与帮助」页会打印）。
注意这台电脑有两个 IPv4，`172.16.40.169`（以太网，首选）才是要发出去的那个。

**外网（隧道）**：双击 `外网分享给别人看.cmd` → 窗口里绿色打印的那行 `https://xxxx.trycloudflare.com`
（`xxxx` 是随机词，文档里的 `https://xxxx.trycloudflare.com` 只是占位符，抄它打不开）→
把地址发人；关掉那个窗口就等于停止分享（也可以双击 `停止外网分享.cmd`）。
隧道由 Cloudflare 免费提供，不需要账号、不需要动路由器。

可靠性与使用要点（都是实测踩出来的）：

- **等窗口出现"✅ 已验证：这个地址现在就能打开"再发出去**：脚本拿到地址后会自己请求一次登录页，
  返回 200 才说可用。**刚建好/刚重连的 30-90 秒内，域名还没解析出来**（实测本机报
  `DNS name does not exist` / 浏览器 `ERR_NAME_NOT_RESOLVED`），这是正常现象，等一下就好。
- **断线会自动重连**：cloudflared 的快速隧道在边缘连接被掐断时会直接退出
  （日志 `Connection terminated` + `no more connections active and exiting`），
  此时旧地址立刻变成 Cloudflare 530 打不开。守护脚本（`tools/share_public.ps1`）会在退出后
  自动重建，并打印/复制/写入**新的**地址。用的是 TCP(HTTP/2) 而不是默认 QUIC，避免网络掐 UDP。
- 地址每次重建都会变；当前地址同时写在 `当前分享地址.txt` 里，并由脚本复制到剪贴板。
- 停止：关掉分享窗口，或双击 `停止外网分享.cmd`（会先留停止标记再结束进程与窗口，
  实测停止后不会自动重连）。

分享出去后对方看到的流程：**先登录页 → 自助注册或你发的账号 → 免费版（看工作台、看商品库、
模拟评论）**；要完整功能就在「用户管理」给他发激活码，或直接建号时选专业版。

- 隧道是 HTTPS，所以**远端也能用麦克风/摄像头**；而局域网 `http://` 访问时，浏览器会禁掉麦克风
  （实测 `navigator.mediaDevices` 为 `undefined`，本机 `127.0.0.1` 不受限）。
- **数字人画面**走 WebRTC 直连（两端都配了 STUN 打洞），不走隧道。服务端能拿到公网候选
  （`tools/smoke/_probe_webrtc_ice.py` 可验证），所以远端**有**机会看到画面，但对称 NAT /
  运营商大内网会失败。要"保证"远端能看到，需要 TURN 服务器或改用 HTTP-FLV/HLS 播放。
- **公开分享前建议关掉自助注册**（「用户管理 → 登录设置」取消勾选"允许用户自助注册"）：
  否则拿到地址的任何人都能注册账号；而安全操作（停播、打断、紧急停止）对**任何已登录用户**
  都放行（这是刻意设计：安全第一），陌生人可能误触停掉你的直播。
- 隧道地址每次重启都变（快速隧道的特性），且只在窗口开着时有效。

## 九、忘记密码 / 常见问题

**忘记管理员密码**（在 `E:\AiLive` 下）：

```
双击 重置管理员密码.cmd
```

或命令行：

```powershell
cd E:\AiLive\LiveTalking
E:\AiLive\env\python.exe -m server.auth_manager list                  # 列出用户
E:\AiLive\env\python.exe -m server.auth_manager set-password admin 新密码
E:\AiLive\env\python.exe -m server.auth_manager make-admin 某用户
E:\AiLive\env\python.exe -m server.auth_manager new-code 30 5         # 生成 5 个 30 天激活码
```

**页面一直跳登录页**：确认服务已重启（旧进程没有鉴权代码）、浏览器允许本站 Cookie、时间没有偏差过大。

**改密码时提示"密码需要同时包含字母和数字"**：这是规则不是故障 —— 纯数字/纯字母都不允许。换成
`ailive2026` 这类带字母+数字的口令即可。**看到这条提示就说明密码没改成功**（弹窗不会关闭）。

**手机登录不了**：手机与电脑需在同一 Wi-Fi（或同一 ZeroTier 虚拟网）；工作台「接入与帮助」页里有手机访问地址。参考 `LiveTalking/docs/mobile_dual_end_deployment.md`。

**用户说"功能是灰的/点了提示升级"**：这是免费版的正常表现。到「用户管理」确认该用户 `plan` 是 `pro` 且到期时间未过期。

**想给某人临时全功能**：用户管理里把 `plan` 设为 `pro`、天数填几天；或把 `role` 设为 `admin`（等于永久全功能，慎用）。

## 十一、几个容易踩的坑（都已在代码里处理）

- **HTML 页面不缓存**：页面响应带 `Cache-Control: no-store`。否则浏览器会"启发式缓存"页面外壳，
  管理员访问过 `/admin_users.html` 之后，同一浏览器里的普通会员再打开可能直接拿缓存、根本不请求服务器。
- **上锁的按钮保持可点击**：给按钮设 `disabled` 浏览器就不会派发 click，用户点了毫无反应；
  现在锁定元素保留可点击，点一下才弹出"需要专业版"并跳转升级页。
- **自助注册限流只针对自助注册**：每 IP 每小时 5 次。管理员在后台批量开号不受此限制
  （否则同一个后台 IP 开到第 6 个就会被"注册过于频繁"卡住）。
- **改了 `common.css` / `common.js` / `auth.js` 要同步提升 `web/sw.js` 里的 `CACHE` 版本号**，
  否则老浏览器会一直用缓存里的旧脚本（第一次打开要再刷新一次才生效）。
- **`common.js` 必须写在页面内联脚本之前**：内联脚本常常第一行就 `LT.Nav.inject(...)`，
  库脚本若放在文件末尾，整块内联脚本会以 `LT is not defined` 立即中断 —— 页面看着正常，
  实际导航和所有按钮都没反应（`tts/index.html` 就是这么坏掉的，现已修好并被静态检查器守住）。
- **停用登录等于对全内网开放**：`AILIVE_AUTH=off` 或后台关掉"启用登录验证"后，所有人免登录可用全部功能，
  只适合完全可信的内网。
