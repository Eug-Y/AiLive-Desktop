## 三、验收中发现并修掉的真问题

| # | 问题 | 根因 | 处理 |
| --- | --- | --- | --- |
| 1 | 服务启动即崩 `ValueError: already has a '*' handler` | 用 `add_route("*")` 注册后台接口，aiohttp_cors 无法给通配路由补预检处理器 | 改逐方法注册；新增 `_check_app_wiring.py` 固化检查 |
| 2 | 兑换页永远停在"正在读取账号状态…" | `upgrade.html` 用了 `Auth.*` 却没引入 `auth.js` → `Auth is not defined` | 补 `<script src="/auth.js">`；静态检查器新增"用到 Auth/LT 必须引入对应 js"，并覆盖全部页面 |
| 3 | 免费版点锁定按钮毫无反应 | 给按钮设 `disabled` 后浏览器不派发 click，升级提示永远弹不出来 | 按钮/链接保持可点击 + 捕获阶段拦截 → 提示并跳升级页；输入框用 `readonly` |
| 4 | 初始密码弹窗每次加载都盖住后台 | `mount()` 无条件弹窗 | 每个浏览器会话最多自动弹一次，顶部横幅常驻提醒 |
| 5 | 会员能打开 `/admin_users.html` 页面外壳 | HTML 响应没有 `Cache-Control`，浏览器启发式缓存了管理员看过的页面，**根本不请求服务器** | 页面响应统一 `no-store, must-revalidate`（已用响应头验证） |
| 6 | 管理员批量开号被"注册过于频繁"卡住 | 每 IP 每小时 5 次的限流也作用在管理员开号上 | 限流只作用于自助注册路径 |
| 7 | 用户"改了管理员密码"其实没生效（以为成功，实际仍用旧口令） | 口令规则要求同时含字母和数字，纯数字被服务端拒绝，而提示只是一行灰色小字，容易被忽略 | 修改密码弹窗改为**本地先校验 + 红字提示 + 弹窗不关闭**，规则与文案前后端一致；E2E 增加"纯数字新密码必须当场被拦下"回归项 |
| 8 | 双击「一键启动AI数字人.cmd」直接失败：`字符串缺少终止符: '。` + `AI digital human startup failed` | 我早前用编辑器改 `tools/start_ai_live.ps1` 里那行中文提示，文件从 **UTF-8 带 BOM** 变成了不带 BOM；PowerShell 5.1 对无 BOM 的脚本按系统 ANSI（GBK）解析，中文串的字节吃掉了收尾引号。（`.cmd` 本身是纯 ASCII，没坏） | 补回 UTF-8 BOM（内容一字未改，已用 5.1 解析器验证 0 错误 + 实跑退出码 0）；新增 `tools/smoke/_check_script_encoding.py` 守卫；**顺带发现 `tools/build_mobile_apk.ps1` 早已因同样原因损坏（3 个解析错误），一并修好**；启动器未登录时改为直接读取本机局域网地址，双击就能看到手机访问地址 |
| 9 | 「参赛项目」加了 `data-hide-without` 后，普通用户在大多数页面**照样看得见** | 全站 24 个页面会渲染同一个导航，但只有 3 个页面（工作台/升级页/用户管理）引入了 `auth.js`；隐藏逻辑写在 `auth.js` 里，其余 21 页根本不执行 | 隐藏逻辑移到导航的生成者 `common.js`：自己读一次 `/api/auth/me`（页面装了 auth.js 就直接复用其状态，不重复请求），`auth.js` 改为回调它；**实测 6 个页面 × 免费/管理员两种身份全部一致**，并加了"未登录访客也看不到"的回归项 |
| 10 | `/tts/index.html` 与 `/tts/index-en.html` **整页 JS 全废**：没有导航，所有按钮无反应 | 内联脚本第 1 行就调用 `LT.Nav.inject`，而 `common.js` 被放在文件末尾引入 → 整块内联脚本以 `LT is not defined` 立即中断（页面外观正常，所以一直没被发现；`tts/` 是子目录，页面检查器原先只扫顶层目录，也漏掉了） | 把 `common.js` 移到内联脚本之前（两个文件都改）；`_check_web_pages.py` 新增"脚本引入顺序"检查并把子目录纳入扫描范围 |
| 11 | 加了「同一账号只能一处登录」后，原有"改密会把旧会话踢下线"的回归项**会因为错误的原因通过**（旧会话其实是被单点登录先挤掉的） | 冒烟脚本第 5 步先用另一个客户端登录同一账号，单点登录把这台挤下线，于是后面那句 401 断言不再能证明"改密"生效 | 该断言改名为"旧会话最终失效（单点登录 + 改密）"；另加一组**隔离**测试：临时 `AILIVE_SINGLE_SESSION=off` → 两处同时在线 → 只改密码 → 另一处才失效，从而真正验证"改密踢会话"这条独立机制 |
| 12 | **发出去的分享地址打不开**（用户在验收后遇到，报"xxxx.trycloudflare.com 打不开"） | 三个原因叠在一起：①文档/窗口里写的 `https://xxxx.trycloudflare.com` 是**占位符**，照着抄必然打不开；②那次的隧道进程已退出（日志 `Connection terminated` → `no more connections active and exiting`），地址变成 Cloudflare **530**；③**新隧道域名有 30-90 秒 DNS 传播延迟**，实测刚建好时三个解析器全返回 `DNS name does not exist`，30 秒后才解析出来（浏览器同一时刻报 `ERR_NAME_NOT_RESOLVED`），而 Chromium 那次刚好撞在这个窗口里 | 分享脚本重写为守护版 `tools/share_public.ps1`：进程退出自动重连（TCP/HTTP2 取代 QUIC）、把地址打印+复制到剪贴板+写入 `当前分享地址.txt`、**并自己请求一次登录页验证（200 才显示"✅ 已验证"）**；停止改为"停止标记 + 结束进程与窗口"（实测停止后不会自动重连）；文档统一说明 `xxxx` 是占位符、要等 30-90 秒解析、发出去之前先自己打开一次 |

另外把浏览器验收脚本本身也加固了：用条件轮询代替固定 sleep、Service Worker 转发 302 时 `page.url` 晚一拍、
步骤页需要先切标签、Playwright 会把 `aria-disabled` 当不可点（真实浏览器会派发 click，需 `force=True`）。

## 五、日常使用与维护要点

- 管理员账号：**初始**为 `admin` / `admin123456`（已在本机按要求改掉，默认口令实测 401 失效）。
  本机现有两个管理员可选：你指定的那个新账号，以及原名 `admin`（口令同样已更新）。
  改口令/忘记口令：双击 `重置管理员密码.cmd`，或
  `E:\AiLive\env\python.exe -m server.auth_manager set-password <用户名> <新口令>`（工作目录 `LiveTalking`）。
- 口令规则：≥8 位且**必须同时包含字母和数字**（纯数字会被拒）。
- 自检脚本不写死口令，跑之前用环境变量传入：`$env:AILIVE_ADMIN_USER` / `$env:AILIVE_ADMIN_PASSWORD`。
- 登录数据目录：`LiveTalking/data/auth/`（users.json / sessions.json / codes.json / config.json，已被 .gitignore 忽略）
- 关闭登录（回到旧的无鉴权行为）：`AILIVE_AUTH=off` 或后台关掉"启用登录验证"——**等于对全内网开放全部功能**，仅限可信内网
- 关闭自助注册：后台设置或 `AILIVE_ALLOW_REGISTER=off`
- **同一账号只允许一处登录**：默认开启，新登录会把该账号其它设备的会话挤下线；**管理员不受限**
  （管理员要多浏览器、自检脚本也用管理员账号，否则每跑一次自检就掉一次线）。
  后台可关（「用户管理 → 登录设置」），或 `AILIVE_SINGLE_SESSION=off` 临时关掉。
- **公开分享（外网隧道）**：双击 `外网分享给别人看.cmd` 得到 `https://xxx.trycloudflare.com`，
  关闭窗口即失效；双击 `停止外网分享.cmd` 可强制停。隧道是 HTTPS，所以远端麦克风可用；
  但**数字人画面走 WebRTC 直连（不走隧道）**，只靠 STUN 打洞 —— 服务端能拿到公网候选
  （`_probe_webrtc_ice.py` 实测 `112.49.158.3:33237`），能否成功取决于双方 NAT；
  要保证远端看到画面需 TURN 或 HTTP-FLV。**公开前建议关掉自助注册**：
  安全操作（停播/打断/紧急停止）对任何已登录用户都放行，陌生人注册后可能误触停播。
- 改前端公共脚本（`common.css` / `common.js` / `auth.js`）后**必须提升 `web/sw.js` 的 `CACHE` 版本号**，否则老浏览器一直用旧缓存
- 自检反复跑请用 `_cleanup_test_data.py --apply` 清理 `e2e*` / `diag*` 账号与自检激活码
- **改过 `.ps1` 脚本后必须确认它仍是 UTF-8 带 BOM**：含中文的 PowerShell 脚本一旦丢了 BOM，
  Windows PowerShell 5.1 会按 GBK 解析，中文串会吃掉后面的引号，脚本直接解析失败
  （症状是双击启动器报 `字符串缺少终止符` / `AI digital human startup failed`）。
  改完跑一次守卫即可确认：

  ```powershell
  E:\AiLive\env\python.exe E:\AiLive\tools\smoke\_check_script_encoding.py        # 只查启动器
  E:\AiLive\env\python.exe E:\AiLive\tools\smoke\_check_script_encoding.py --all  # 全盘扫，只报警告
  ```
- `.cmd` 里含中文时必须有 `chcp 65001`（本项目的「停止AI直播服务.cmd」「重置管理员密码.cmd」
  「外网分享给别人看.cmd」「停止外网分享.cmd」都有）；两个新脚本也已被编码守卫纳入检查清单
