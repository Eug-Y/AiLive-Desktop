# 声音克隆录音素材（单段）

**一段到底，60–70 秒。** 音素覆盖和直播语气都压在这段里，不用分段录。
必须你本人朗读，不要用 AI 音频去克隆。

---

## 录音要求

| 项目 | 要求 |
|---|---|
| 设备 | 手机麦克风或耳麦即可 |
| 距离 | 嘴到话筒 15–20 cm，侧向 30° 避开气流 |
| 房间 | 有衣物、被褥、书架的卧室；避开空旷客厅和卫生间 |
| 环境音 | 关空调、风扇、加湿器，手机开飞行模式 |
| 格式 | WAV 优先；m4a 也可，码率拉最高 |
| 语速 | 每秒 4.5–5.5 字，比念课文快，比喊麦慢 |
| 状态 | 用实际直播的语气，不要端播音腔 |

按标点自然停顿就行：句号停半秒，段落之间停一秒。

---

## 正文

欢迎来到直播间，我是你们的老朋友。今天这场咱们不整虚的，上来就直接上硬货——先给大家看一款我们直播间回头率最高的东西，品质和价位我都帮你们把过关了。

先说结论：如果你正在找一件日常用得住、不折腾的，这一款闭眼入就行。颜色有两个，浅色温柔百搭，深色耐看显质感，纠结的话就选浅色。

它最让我意外的是细节。玻璃杯、陶瓷盘、木托盘，随手一放都好看；桌上的杂志、窗台上的绿植、旁边那杯茉莉花茶，拍出来就跟样板间一样。姐姐昨天来我家看到，当场就拿走了一个。

数量真的不多，我这边后台看着往下掉。喜欢的家人抓紧，右下角小黄车点进去就能看到，页面往下滑一点儿就是，拍下之后四十八小时内发货。

一共三百二十八件，优惠力度是六点五折，到手价一百九十九，满二百九十九包邮，活动到今晚十二点结束。有任何问题随时找客服，咱们售后是兜底的，这个你放心拍。

## 这段覆盖了什么

- 声母：b p m f d t n l g k h j q x zh ch sh r z c s 全部出现
- 韵母：ü（绿）、儿化（一点儿）、轻声（的 / 了 / 们 / 着）都在
- 数字：328、6.5 折、199、299、48 小时、晚十二点
- 节奏：长句与短句交错，快慢有变化

如果模型需要读英文，把末段的「小黄车」换成「链接在 SKU 三号位」再录一句即可。

## 上传前必做

「参考文本」必须和你**实际念出来的字**完全一致。

1. 点「识别」自动转录
2. 人工核对：数字（328 / 6.5 / 199）、语气词（咱们、好嘞）、标点
3. 你临场改词的地方，文本跟着改

错一个字，克隆出来的音色就开始漂。

## 录完自检

- [ ] 回放没有回声、电流声、空调嗡鸣

- [ ] 语气是直播状态，不是念稿状态
- [ ] 文件 ≤ 10 MB
- [ ] 参考文本已逐字校对
