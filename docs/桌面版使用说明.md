## 五、技术要点（改代码前看这个）

1. **单文件、零依赖**：没有 `<script src>`、没有 `<link>`、没有外部图片，图标全部是内联 SVG。
   所以它不会被网络、CDN、字体影响，拷到任何机器上双击就能跑。
2. **窗口系统**：绝对定位 + `z-index` 分层（`#winLayer` 层内递增），窗口对象由 `WM` 管理
   （`WM.wins` / `WM.order`），最小化不销毁 DOM，因此 iframe 里的 WebRTC 连接不会因为最小化而断。
3. **拖动/缩放用 `setPointerCapture`**：指针一旦被标题栏/把手捕获，即使拖动过程中划过 iframe 也不会丢事件；
   配合 `#dragShield` 遮罩与 `body.dragging` 避免 iframe 抢鼠标。
4. **状态与接口**：`Data` 层统一封装 `GET/POST/PUT/DELETE`，兼容两种返回体——
   `{code,msg,data}`（`/api/live/*`）会拆出 `data`，`/api/workflow/*` 直接返回对象。
   轮询间隔默认 4000ms（设置里最小 2000ms），驱动各窗口的 `onStatus` 回调与状态变化通知。
5. **演示模式**：`DEMO` 对象提供与真实接口同形状的数据，`PanelRegistry.demo` 负责在没有真实页面时渲染窗口，
   保证离线也能看到完整界面而不报错。
6. **不改动原有页面**：`live_console.html`、`live_output.html` 等一行都没改，桌面版只是把它们放进窗口。

## 七、排障

| 现象 | 原因与处理 |
| --- | --- |
| 徽标显示「离线演示」但服务明明是开的 | 你是用 `file://` 打开的离线副本；改用 `http://127.0.0.1:8010/app.html`（v1.3.2 起统一入口；老书签里的 `/desktop.html` 也会 302 到这里） |
| 窗口里显示「该页面属于专业版功能…」 | 当前账号是免费版；这是服务端的权限判定，用激活码升级即可 |
| 窗口里是空白/一直转圈 | 真实页面自身加载慢或报错，可点窗口工具栏的「刷新」；日志诊断窗口里能看到前端错误记录 |
| 设置改了没生效 | 设置存在浏览器 localStorage；换浏览器/无痕窗口会回到默认 |
| 手机上看图标点不开 | 窄屏下窗口是全屏的，先点任务栏最右侧「显示桌面」回到桌面 |
| 双击图标没反应 | 设置里开关是「双击打开」，触屏请用单击；或图标被其它窗口挡住了 |
| **双击「桌面版AI数字人.cmd」没反应 / 只剩一句 `'nul' is not recognized`** | 批处理文件被改成了 **LF 行尾**。含 `chcp 65001` 的 `.cmd` 在 bare LF 下，cmd 换代码页后会按字节偏移读错行、把后面的命令切碎执行（2026-10-11 实测复现）。**保持 CRLF 行尾**，并跑 `E:\AiLive\env\python.exe E:\AiLive\tools\smoke\_check_script_encoding.py` 复查——这条规则已写进守卫，再犯会直接报错 |

## 八、v1.3.2：网页端入口统一（旧仿桌面页退役）

用户反馈「网页端还提供旧版假桌面页」后做的收口。服务端只改了一处（`LiveTalking\server\routes.py`）：

```text
GET /             → 302 /app.html      （webrtc 传输；rtmp/rtcpush 仍进各自控制页 rtmpapi/rtcpushapi）
GET /desktop.html → 302 /app.html      （老链接、老书签不再落到假桌面页）
GET /app.html     → 200                （统一外壳，桌面端与网页端同一份界面）
GET /live_console.html → 200           （单页工作台仍然可以直接访问，没删）
```

未登录时仍是先被服务端挡到登录页（`/desktop.html` → `login.html?next=/desktop.html`，登录后再 302 到外壳）。

配套动作：

* 旧页面文件 `LiveTalking\web\desktop.html` 与离线留档副本 `desktop\AI数字人桌面版.html` **都还在**，只是不再作为入口
  （假桌面那套模拟窗口/任务栏/开始菜单已经被真桌面应用取代，没必要再留第二个界面）。
* 旧的真实服务自检 49 项（`_e2e_desktop_ui.py`）连同说明归档到 `E:\AiLive\archive\legacy-fake-desktop\`：
  它测的页面已不由服务端提供，留着会一直红，归档并在文件头写清原因与复跑条件。
* 验收改由统一外壳的两套脚本覆盖：网页端 `_e2e_app_ui.py` **70/70**（含 5 项入口统一断言）、
