分享给别人看：
1. 同一个 Wi-Fi / 同一条网线的人：直接把 http://172.16.40.169:8010/app.html 发给他（统一界面；
   旧的 http://172.16.40.169:8010/live_console.html 仍然能用；发根地址 http://172.16.40.169:8010 也会自动跳到 app.html）。
   服务监听 0.0.0.0，防火墙已放行本项目的 python（Public/Private 都允许），不用再设置。
   这台电脑以太网是 172.16.40.169（首选），Wi-Fi 那个 172.16.40.170 已被系统标记为 Deprecated，
   所以发 .169 这个；启动器窗口和“接入与帮助”页里报的也是它。
2. 不在同一个网络的人（外地、手机流量、评委在别的城市）：双击“外网分享给别人看.cmd”，
   窗口里会用绿色打印一行真地址（形如 https://随机词-随机词.trycloudflare.com），
   它同时会被复制到剪贴板、并写进“当前分享地址.txt”。把这一行原样发给别人就能打开。
   注意：文档里写的 https://xxxx.trycloudflare.com 只是占位符（抄它当然打不开）。
   窗口里出现“✅ 已验证：这个地址现在就能打开”再发出去最稳妥；
   刚建好/刚重连的头 30-90 秒域名还在解析（本机实测这段会报“找不到服务器”），稍等即可。
   隧道断了脚本会自动重连（地址会变，看窗口里新的那一行），不会像以前那样悄悄失效。
   关掉那个窗口 = 停止分享；也可以双击“停止外网分享.cmd”强制停（已验证：停了不会自己重连）。
   隧道免费、不需要账号、不动路由器；地址每次重启都会变，只在窗口开着时有效。
3. 对方打开会先看到登录页：自助注册开放，注册后是免费版（看工作台、看商品库、模拟评论；
   不能开播）。要完整功能请你在“用户管理”页给他发激活码，或直接建一个专业版账号。
4. 外网隧道是 https，所以对方那边麦克风/摄像头能用；局域网 http 访问时浏览器会禁掉麦克风
   （实测 navigator.mediaDevices 为 undefined；本机 127.0.0.1 不受限）。
5. 数字人“画面”走 WebRTC 直连，不走隧道：能不能在远端看到，取决于两边网络的打洞情况
   （本机实测能拿到公网候选 112.49.158.3，属于有希望但不保证）。
   最准的验证办法：用手机流量打开你发出去的地址试一次。
   如果远端看不到画面，就让 AI 助手配 TURN 或改成 HTTP-FLV 播放（走 https 隧道没问题）。
6. 公开分享前建议先关掉自助注册（“用户管理 → 登录设置”取消“允许用户自助注册”）：
   否则拿到地址的任何人都能注册账号，而“停播/打断/紧急停止”这类安全按钮对任何已登录用户都放行，
   陌生人可能误触、把你的直播停掉。

音色库（语音合成页 · 预录音色）：
1. 桌面版左导航「核心 → 语音合成」，或浏览器打开 http://127.0.0.1:8010/tts/index.html。
2. 页面上方「语音合成服务地址（TTS）」留空就是本机 8010 自带的音色库；点「连接测试」加载列表。
3. 列表里有三类音色：
   · 预设语音（晓晓/晓伊/云希…7 个，Edge TTS）：能朗读任意文本，但需要联网。
   · 本机语音（慧慧 等，Windows 系统自带）：也能朗读任意文本，而且**完全离线**；
     断网或 Edge 接口被微软拒绝（403）时，选预设语音合成会自动用「慧慧」兜底，不会哑掉。
     如果合成报 403，执行 env\python.exe -m pip install -U edge-tts 后重启服务即可。
   · 已上传（预录音色）：音频素材\1.m4a、2.m4a 已登记成「音色一」（1 分 20 秒）、「音色二」（1 分 38 秒）。
     点 ▶ 直接试听原声，点 ✓ 选用；它们只能回放原声，朗读新文本会被拒绝并提示改用预设或本机语音
     ——本机没有零样本音色克隆模型（models 目录里只有 wav2lip.pth），这点不糊弄。
4. 音色文件都在 LiveTalking\data\voices\<音色名>\（sample.m4a 原始、sample.wav 16k 单声道、meta.json）。
   再登记别的录音：env\python.exe tools\register_voice_samples.py（默认只补缺，--force 覆盖，--list 查看），
   也可以直接在网页上「上传克隆音色」——现在上传走本机音色库，不再依赖外部服务。
5. 要真正做「音色克隆」（用新音色朗读任意文本），需要接入带克隆能力的 TTS 服务（如 CosyVoice /
   IndexTTS2 的 API），把它的地址填到上面那个服务地址里即可；原先默认的 http://localhost:8091
   （vLLM Omni）本机没有部署，所以之前上传必然失败。

防录播（平台判“录播 / 无人直播”看的是固定周期重复，不是有没有人坐在旁边）：
1. 工作台默认：话术间隔 30 秒、“打乱话术顺序（防录播）”开启。
2. 只要开着“循环播放”，间隔不足 15 秒会被自动上浮到 15 秒（含以前的 8 秒旧数据）。
3. 每条之间还有 ±35% 随机抖动；新一轮的第一条不会和上一轮最后一条相同。
4. 开播检查中心新增两项必做人工确认：“值守痕迹可观测（真人实时读评论并回应）”
   和“百货各子类目资质已核对”，另有一项防录播自动提示（橙色，不阻塞开播）。
5. 最稳的做法是关掉“循环播放”，由值守人员逐轮手动继续——每次继续都有人操作。

断网保命（离线语音缓存）：
1. 联网时执行：E:\AiLive\env\python.exe E:\AiLive\tools\prewarm_tts_cache.py
2. 该命令把高频问题话术（价格、规格、发货、售后等）合成为本地语音缓存，断网也能播、且接近零延迟。
3. 工作台“开播 SOP 检查中心”会显示“离线语音缓存已覆盖高频话术”的覆盖率。
4. 新增商品、修改价格或话术后，请重新执行预热；换音色后也必须重新预热。

模拟评论测试（开播前自检 / 演示 / 排障）：
1. 打开工作台 http://127.0.0.1:8010/live_console.html，找到“6. 模拟评论测试”。
2. 输入一句观众评论（或点“价格 / 规格 / 售后 / 未命中示例”快捷按钮），点“模拟一条评论”。
3. 结果会显示：走了哪条链路（T1 意图直答 / T2 大模型回答）、命中的意图与命中词、
   将播报的话术、这句话断网时能不能播（离线可播）、判定耗时、是否已播报。
4. 勾选“同时让数字人播报”可让数字人直接说出来，前提是已打开并连接直播输出窗口。
5. 未命中问题走 T2，需要先在大模型管理页配置 API Key，否则会提示“API Key 尚未配置”。
